1. The Clique Partition Problem with Minimum Clique Size Requirement
    - partitioning the vertices of graph G into subcliques that each have at least S vertices, so as to minimize the total weight of the edges that have both endpoints in the same subclique
    - pigeon cutting planes and flower cutting planes
    - triangle constraints, 2-partition constraints
    - CPP variation
        - requires dividing the vertices into 2 clusters of equal size
        - k-way equipartition problem
1. Fixed set search applied to the clique partitioning problem
    - To address this NP-hard combinatorial optimization problem, the novel fixed set search (FSS) metaheuristic is applied
        - firstly, develop a greedy randomized adaptive search procedure (GRASP) using a new type of neighborhood in the local search
        - The GRASP is further extended to the FSS by adding a learning mechanism
    - The FSS application to the CPP provides a new approach for generating fixed sets for problems with solution symmetries
