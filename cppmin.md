# Branch-and-price-and-cut on the clique partitioning problem with minimum clique size requirement

- LP relaxation is not a good approximation of the original IP problem. When $n$ is not a multiple of $S$, there exists a fractional solution to MLP that has a better objective value than the optimal integer solution.
- we can decide whether to expand T or not by solving a minimum node-edge-weighted cluster problem (MINNEWCP) 
- we use a simply heuristic, Algorithm 1, to check only those subsets generated by combining the corresponding columns of two fractional variables in the current optimal (MLP) solution. 
- MINNEWCP: The MINNEWCP problem is to select a subset of the vertices P ⊆ V that minimize the difference between the cost of the edges in E(P) and the weight of the vertices in P.
    - By the change of z = 1 − y, we can formulate the MINNEWCPQP as a QKP with an additional constraint
- Since solving the pricing problem as an IP problem is an expensive operation, we first use some heuristic algorithms to try to generate columns before calling the IP solver.
- Only when the previous algorithms do not generate any columns to be priced in, would we try the next algorithm.

## LP

 - $w_P = \sum_{e\in E(P)} w_e$ weight of a cluster
 - $c_{i,j}$ edge cost

### **MIP**

$
\min\sum\limits_P w_P x_P \\
s.t. \sum\limits_{P:v\in P}x_P = 1, \forall v \in V \\
x_P \in \{0, 1\} \\
P\in 2^V, |P|\geq S  \\
$

### **MLP**

$
\min\sum\limits_P w_P x_P  \\
s.t. \sum\limits_{P:v\in P}x_P = 1, \forall v \in V  \\
x_P\geq 0  \\
P\in 2^V, |P|\geq S \\
$

### **RMLP**
$\min\sum\limits_P w_P x_P$  
$s.t. \sum\limits_{P:v\in P}x_P = 1, \forall v \in V$  
$\sum\limits_P x_P \leq k$  
$\sum\limits_{P \subset Q_i} x_P \leq \lfloor |Q_i| / S \rfloor, i = 1 \ldots q$  
$x_P \geq 0$  
$P \in T \subset 2^V, |P| \geq S$

### **MINNEWCP**

- $a_v$: each vertex $v$ has a cardinality(基数) $a_v$ - node weight 节点权重
- $Q \subseteq V$ is a given subset of $V$
- $q$ is also a give number
- $Q_i$: we can partition Q into at most $q-1$ clusters that contain at least S vertices
- $c_{i,j}$ in $C$ is the edge weight for edge (i,j)
- $n$ the number of vertices

$
\min \frac{1}{2} y^T C y - \pi^T y \\
\text{s.t.} a^T y \ge S \\
\sum\limits_{v\notin Q_i} a_v y_v \ge 1, i = 1,\ldots,q \\
y_v \in \{0, 1\}
$

## Variables

- q: 等同于k，划分成至多q-1个簇
- k
- $x_P = 1$, if cluster $P$ is used in the solution of CPPMIN
- S: at least $S$ vertices
- xlp: solution LP relaxation solved by CPLEX
    - there are $2^V$ variables in $xlp$
